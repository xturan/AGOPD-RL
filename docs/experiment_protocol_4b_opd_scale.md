## 1. Part A(便宜,无新训练)——组内信号密度指数

不训模型,直接从普查 p̂ 分布算"能形成正负对比的组比例":

```
S(G) = E_p̂[ EGR(p̂;G) ] = E_p̂[ 1 − (1−p̂)^G − p̂^G ]
```

- G 取 6(与表 2 主协议一致),也可给 G=4/8。
- 1.7B 用全量普查(16,164,现成);4B 用本次真普查(2,000×n=8,CI)。
- 输出:两尺度 S(6) 与 95% 区间;若 4B S(6) ≫ 1.7B,则"信号密度随学生能力上升"有了同口径量化(不只 p̂=0 占比),可作为正文/附录 A.3 的一张图或一个数字。

## 2. Part B(需运行,待批准)——4B 学生 OPD 受控对照

### 2.1 研究问题(RQ)
在 4B 学生(更强探索)上,无条件加入 OPD 是否仍像 1.7B 那样相对 GRPO 显著下降(−4.30 pp)?教师门控 / RFT 的相对行为如何随规模变化?

### 2.2 教师选择(必须先行决策——这是当前最大坑)
- **理想**:需要一个对 4B 学生"题目级更强"的教师。现有 8B Base 语义弱于 4B Base,不合格;4B-GRPO-50 语义=40.23% 也不高于 4B Base 的 41.02%。→ 需要先训 8B 后训练教师(GRPO ~50–120 步,4×A100,数小时),顺带回答"8B RL 是否产生更强教师"(R57 遗留问题)。
- **备选(打折)**:教师=4B-GRPO-50。快,但语义不占优;结论要注明教师强度受限。
- 两种都要求:教师相对学生的题目级优势(chat-template 同题重测)先行测量并在方案里报告。

### 2.3 训练通道(必须与 GRPO 基线同通道)
- 历史教训:LoRA r8+lr1e-6 通道作废;**已证明有效的通道** = LoRA r16 + lr1e-4(Run C:Pure GRPO strict 42.48);full-param 4B OPD 曾因宿主机 `Exclusive_Process` 拓扑未跑成。
- 方案 A(full-param):先解决拓扑(学生 FSDP 与教师 vLLM / rollout 分卡),完全镜像 §5.1 四臂;最干净但工程风险最高。
- 方案 B(LoRA r16/lr1e-4):所有臂同用该通道,与 Run C Pure GRPO 直接对比;成本低、可先出信号。**任选其一时,对照基线必须同通道**(不能拿 full-param 40.23 与 LoRA 臂比)。

### 2.4 臂与协议(以方案 B 为例,镜像 §5.1/表 2)
| 臂 | 目标 | 备注 |
|---|---|---|
| 4B Pure GRPO | 结果奖励 RL | 基线;可用 Run C 已有检查点或重跑同批数据 |
| 4B Vanilla OPD-only | 硬目标词元蒸馏 | 判断纯蒸馏是否仍劣于 Base |
| 4B RL+OPD | GRPO + 无条件 OPD | 核心:Δ vs Pure GRPO |
| (可选) 4B AGOPD | + 优势门 + 胜任门 | 判断门控收益是否随规模变化 |

- 数据:与 1.7B 负迁移可比,取**同一固定 1,472 题训练池**(comfort,构建见 §2.1/附录 A);若算力紧,先 120 题池 60–120 步出方向,再上全池。
- 组大小 G=6、batch 8、lr 与通道按上面;decode T=0.6/top-p .95/top-k20/2048 上限;seed 42;固定 1,024 题 @2048 非思考评估;逐题配对 bootstrap 95% CI + McNemar(与主表一致)。
- 训练健康量:distill loss、策略熵、响应长度,判断"OPD 信号是否转化为收益"。

### 2.5 判据(预注册,防事后解读)
- 若 4B **RL+OPD − GRPO 的配对区间不含 0 且为负** → 负迁移在更强学生上仍存在 → "探索不足"不能充分解释,支持"词元级 OPD 目标本身 mismatch",AGOPD 必要性更明确。
- 若区间含 0 或为正 → 支持"学生探索/信号密度决定 OPD 健康性"(要配 Part A 的 S(6) 证明机制),但需 1 个以上 seed 复核。
- 若 Vanilla OPD-only 在 4B 也不如 Base → 纯蒸馏本身在大学生上仍无效,机制结论同上但"健康性"仅指不拖累 RL。
