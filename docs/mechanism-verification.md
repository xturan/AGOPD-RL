# 负迁移的假设与验证链

本文档说明:我们如何**定义**负迁移、提出哪些**相互竞争的解释(假设)**,以及每个假设用**什么实验去证伪**。属于方法说明,不含任何实验运行记录。

## 0. 定义与测量口径

- **负迁移的定义**:相对同数据、同预算、同评估口径的纯结果奖励 RL(GRPO),叠加在线词元级蒸馏后**固定评估显著下降**。
- **口径**:固定 1,024 题验证集;非思考解码;`max_new_tokens=2048`;`temperature 0.6 / top_p 0.95 / top_k 20 / seed 42`;strict 与 semantic 双口径;逐题配对 Δ + 95% CI + McNemar 精确检验。
- **可比性纪律**:需要互相比较的运行显式传 `data.seed=42`;不同训练通道(全参数 / LoRA)不混比。

## 1. 假设集合与各自的证伪实验

| # | 假设 | 若成立的可观测预测 | 验证实验(协议) | 判据 | 入口 |
|---|---|---|---|---|---|
| H1 | **教师绝对能力不足**:教师在这些题上本身不会 | 教师在**题目根状态**上同样弱,且弱区与负迁移区重合 | 根状态同题重测:教师与学生同一批题、同一解码协议;按学生能力分桶看教师优势 | 根状态优势为正且不随能力升高消失 → H1 不足以解释 | `scripts/census_scale.py`、`scripts/build_base_teacher_map.py` |
| H2 | **状态错位**(主假设):监督施加在学生已进入的**错误状态**上 | 教师救援率随**错误前缀加深**单调下降;且该下降不是"上下文变长"造成的 | 以学生真实错误轨迹的前缀比例(25/50/75/100%)截断交给教师续写;加入**等长随机填充**与**等长正确前缀**对照 | 错误前缀 < 随机填充 < 正确前缀,且长度匹配后差异仍在 → 语义错位而非长度效应 | `scripts/counterfactual_teacher_rescue.py`、`scripts/build_matched_state_probe_set.py`、`scripts/collect_state_probe.py` |
| H3 | **监督粒度错配**:轨迹级监督与状态级监督对同一教师能力的要求不同 | 轨迹级(RFT)与在线状态级(OPD)在同预算下出现方向性差异,且 OPD 在错位状态上更差 | 同题配对的人工复核队列:同一批题上比对轨迹级与状态级两组条件 | 配对差异方向稳定(区间/检验见论文) | `scripts/compare_cptr_rft_opd.py`、`scripts/analyze_transfer.py` |
| H4 | **作用域过宽**:无条件施加把监督也给了"学生已答对"与"教师不可解"的状态 | 把作用域收窄到**负优势轨迹 ∩ 教师可解题**后,退化应被收回 | 门控消融:①优势门单独 ②教师胜任门单独 ③两者联合;其余配置完全一致 | 任一单独门控都改善;联合门控回收最大 | `src/agopd/gating/`、`scripts/run_4b8b_verify.sh`(ARM 开关) |
| H5 | **教师弱于学生**(H2 的强化版):固定教师在被蒸馏分布上不如训后学生 | 同题真实生成中,教师正确率**低于**训后学生;蒸馏的净方向偏离正确性 | 教师真实轨迹探针:同一批训练题上让教师/学生各自独立生成并计分;同时记录蒸馏时的教师胜任比例 | 教师低于学生 → 无条件蒸馏必然向更弱目标拉 | `scripts/evaluate_dapo_vllm.py`(教师/学生同协议生成)、`scripts/analyze_4b8b_verify.py` |

## 2. 从"相关"到"因果"的证据分层

- **相关性证据**:H2 的前缀深度曲线、H5 的同题能力对比 —— 说明现象与假设一致,但不排除混杂。
- **剥离混杂的控制**:等长随机填充对照(把"长度"从"语义"中分离)、同题配对(把"题目难度"消掉)。
- **因果性证据**:H4 的门控消融 —— 只改变"监督施加在哪些状态/轨迹"这一个变量,其余(数据、预算、通道、评估)完全不变。若收窄作用域即可收回退化,则"作用域过宽"是**直接原因**而非伴随现象。

## 3. 可复用的判读规则

1. **先证伪强假设**:H1(教师不会)最容易被反驳,先做;否则后续机制讨论建立在错误前提上。
2. **每个假设都必须给出"若成立应看到什么"**,并在实验前写下判据(预注册),避免事后解释。
3. **在线指标与固定评估必须同向**:若在线奖励上升而固定评估下降,应优先怀疑奖励/格式漂移,而不是把它当作机制证据。
4. **教师侧必须先测**:在任何蒸馏实验前,先量教师在**同一分布**上相对学生的逐题优势;教师不占优时,无条件蒸馏的预期收益为负。
