> 原则:附录与正文**同权**,是正文的**深度/广度扩展**(第二轨)。正文负责主张与结论,附录负责"载量回填 / 稳健性背书 / 深度延伸";二者靠**映射索引 + 统一证据状态词表**联动。执行对齐 `docs/restructure_plan_v6.md`(P3:Pass@k 入附录;P5:轨迹级上主文)。

## 0. 审计总判断
病不在"缺内容",而在三类结构病:
1. **无导言/无映射**:六个附录各自起头,读者与审稿人看不到每块"扩展正文哪句主张"。
2. **三样角色混装、篇幅错配**:载量数字(D/E/A1)、存档材料(被拒配置、think-RL、孤儿指标、三例同构案例)、深度延伸(轨迹级迁移)等长平铺;真正重要的"轨迹级=正通道"证据被埋在"谱系+探索性"的壳里。
3. **坏源/孤儿**:A.3 的"4B ≈40%"数字已判无效仍在承托主文解释;表 D1 的 Stage-2B·AGOPD@2048=27.05% 与主表 3 同值同数(待溯源);Stage-2C 30.57/31.35 在 D1∩E1 双表重复(单源原则破坏)。

## 1. 统一"角色 + 状态"词表(全附录只用这一套)
- **角色**:①载量回填(直接支撑正文某数/主张)②稳健性背书(给苛刻审稿人看)③深度延伸(越过正文主线的新方向)。
- **证据状态**:正式统计 / 探索性点估计(非配对) / 诊断量(训练过程) / 方向性观察(缺逐题存档) / 待回填(工件失效或普查未跑)。
- 引用纪律:正文凡引用附录数字,**同句必须带该单位 status 限定**;所有"点估计/非配对/不参与显著性"类句式从各单位正文删去,只在导读"引用规范"集中声明一次,各单位保留一句精简限定。
